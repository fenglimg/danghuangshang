## 页面矩阵

| 页面 | 作用 | 典型动作 |
|------|------|----------|
| 总览 | 看整体运行状态、部门排行、趋势 | 看在线状态、看总量、跳转会话 |
| 朝堂 | 在 Web 端直接下旨 | 选部门、发送指令、看朝堂消息 |
| 治理 | 管 OpenMOSS 任务治理 | 审查、打回、巡检、恢复认领 |
| 部门 | 看部门维度统计 | 看部门在线、Token、消息量 |
| Token统计 | 看 Token 消耗与成本 | 导出、按部门查看 |
| 会话 | 查历史会话与摘要 | 过滤、排序、看消息、导出 |
| 频道 | 看平台 / 频道 / 账号概况 | 检查绑定与平台状态 |
| 节点 | 看节点状态 | 查看节点在线情况 |
| 奏章板 | 看 Notion 侧数据看板 | 查看日报、财务、人员数据 |
| 奏报厅 | 看系统提醒、奏报、异常 | 查看告警与通知 |
| 日志 | 查日志 | 搜索日志、筛选日志 |
| 搜索 | 全局搜索消息/会话/日志 | 输入关键词统一搜索 |
| 定时 | 管理 Cron | 看任务、启停、手动触发 |
| 技能 | 管理 skills / ClawdHub 搜索 | 搜索、安装、启用、禁用 |
| 系统 | 看系统健康 | 查看 CPU / 内存 / 磁盘 / 状态 |
| 设置 | 调系统参数 | 刷新配置、调整阈值 |

## 页面说明

### 总览

适合：

- 第一次登录后先看全局状态
- 快速知道哪个部门最活跃

你会看到：

- 运行概况
- Token 趋势
- 部门排行

---

### 朝堂

适合：

- 不打开 Discord，也想直接在 Web 中下旨

你会做的动作：

- 选一个 Bot
- 直接发命令
- 看最近朝堂消息

---

### 治理

适合：

- 验证 OpenMOSS
- 管任务状态和治理动作

你会做的动作：

- 看任务流
- 查看时间线
- 通过审查
- 打回返工
- 立即巡检
- 恢复认领

---

### 部门

适合：

- 从组织角度看系统

你会看到：

- 每个部门的消息量
- Token 消耗
- 基本状态

---

### Token统计

适合：

- 看成本
- 看输入输出消耗

你会做的动作：

- 看部门排行
- 看占比
- 导出数据

---

### 会话

适合：

- 查历史上下文
- 看某个 agent 到底做过什么

你会做的动作：

- 搜索会话
- 按时间 / Token 排序
- 看消息时间线
- 导出会话

---

### 频道

适合：

- 确认平台接入情况
- 看账号和频道统计

---

### 节点

适合：

- 查看节点设备状态
- 看节点是否在线

---

### 奏章板

适合：

- 从 GUI 看 Notion 数据
- 看日报 / 财务 / 人员等结构化信息

---

### 奏报厅

适合：

- 看系统告警
- 看需要处理的奏报和提醒

---

### 日志

适合：

- 排查问题
- 查消息日志

---

### 搜索

适合：

- 一次性搜索日志、消息、会话

---

### 定时

适合：

- 管理 OpenClaw cron
- 查看任务状态

---

### 技能

适合：

- 查看本地已装技能
- 从 ClawdHub 搜索和安装技能

---

### 系统

适合：

- 看 CPU / 内存 / 磁盘 / Gateway 健康

---

### 设置

适合：

- 做基础系统配置调整
- 设置 Token 告警等参数

---
